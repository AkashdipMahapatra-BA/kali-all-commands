13.2 Reset WSL Password 🔑

Forgot your WSL user password? Use Windows CMD to reset it via root.

# Step 1 — Open Windows CMD (not PowerShell) and set distro to login as root
ubuntu2204 config --default-user root
# (replace ubuntu2204 with your distro name, e.g. kali-linux)

# Step 2 — A root WSL shell opens automatically. Reset the password:
passwd <your-username>
# e.g.: passwd ak2001
# Enter new password when prompted

# Step 3 — Set your user back as default
ubuntu2204 config --default-user <your-username>
